# Governance

SigmaLite is currently maintained by the project maintainers on a
maintainer-led model.

## Decision Making

Maintainers prioritize:

1. User-visible correctness.
2. Security and data safety.
3. Testability and operational clarity.
4. Compatibility with the existing architecture.
5. Small, reviewable changes.

Large or breaking changes should start as an issue or discussion before a PR.

## Maintainer Responsibilities

Maintainers are responsible for:

- Reviewing and merging PRs.
- Triaging issues.
- Coordinating security fixes.
- Maintaining release notes.
- Keeping CI and documentation healthy.

## Contributor Path

Consistent contributors may be invited into a larger maintainer role after
demonstrating high-quality code review, thoughtful issue triage, and reliable
follow-through.

## Releases

Until the project reaches a stable `1.0` release, releases may include beta
limitations and compatibility notes. Breaking changes must be called out in
`CHANGELOG.md`.
