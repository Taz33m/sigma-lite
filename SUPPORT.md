# Support

SigmaLite is an open-source project. Support is provided through the repository
issue tracker and documentation.

## Where To Ask

- Reproducible bugs: open a bug report.
- Feature ideas: open a feature request.
- Security issues: follow [`SECURITY.md`](SECURITY.md), not a public issue.
- Setup questions: check [`README.md`](README.md) and
  [`docs/DEVELOPMENT.md`](docs/DEVELOPMENT.md) first.

## What To Include

For bugs, include:

- Operating system.
- Python and Node versions.
- Backend and frontend commands used.
- Relevant environment variables, with secrets removed.
- Steps to reproduce.
- Expected behavior.
- Actual behavior.
- Logs or screenshots.

For data issues, include a minimal CSV sample that reproduces the problem. Do
not attach sensitive datasets.
