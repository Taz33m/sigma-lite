A CSV is not a workspace.

It has rows, but no structure. Values, but no shared context.

SigmaLite turns that file into a working data surface: upload the dataset, infer the schema, and inspect rows in an editable grid.

Then analysis becomes part of the sheet: filter the data, run aggregate formulas, and turn selected columns into saved charts.

Teams can mark up the work with comments and realtime presence, so the conversation stays attached to the numbers.

And underneath the interface is a real full-stack system: React, FastAPI, pandas, SQLAlchemy, Alembic, WebSockets, CI, and end-to-end checks.

SigmaLite. Spreadsheet-style data exploration, engineered for teams.
